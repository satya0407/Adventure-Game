# Project Title: Adventure Game
## Description: 
This is a text based game where the player can choose a class and give inputs to progress through the game.
## Installation:
1. clone repository
- git clone https://github.com/satya0407/Adventure-Game.git
- cd Adventure-Game
2. intall python 3.10 or newer
## Usage:
to run the code: python kalandjatek.py
- first choose a class, each with different stats (knight, sorcerer, archer, prince, guardian)
- every turn an event happens (like fighting an enemy, finding loot, reaching a place)
- every 5th round the player can buy different items (medkit, sword, spellbook, etc..)
- every 10th round the story continues
- the game ends by finishing the quest, or the death of the character
